# 会话退出与实时监控验证清单

- 退出：正常点击左下角退出，以同源 CSRF POST 导航退出 OIDC；最终进入 `/login`，工作台与 Authentik `/me` 均拒绝旧会话。再次登录要求身份验证。
- 安全：无 CSRF 的退出被拒绝；令牌只存服务端加密、带 TTL 的会话票据，不出现在浏览器 local/session storage；退出删除票据。
- 监控：初次填充最近 6 分钟历史，每 6 秒更新同一曲线，保留已有采样，重复时间去重，时间槽对齐；新样本从右进入，旧样本从左退出。
- 状态：网卡/磁盘、全部/单设备切换；短暂指标请求失败保留历史，缺失采样留空；权限/用户变化与页面卸载清空私有历史。
- 视觉：明暗主题与 390/1440 像素，X 轴只显示稀疏相对时间，无文字重叠或水平滚动；观察至少两次采样后的曲线。
- 图标：Authentik Application Dashboard 的两个入口均显示原鲸鱼标志，内网绿色网络角标，外网侧局域网蓝色地球角标；名称/描述同时标注网络与 IP，媒体上传后不依赖工作台提供图片。
- 探索：退出后后退/重访受保护页面；设备切换后刷新、指标获取失败、手机窄屏。

最终结果另记于实施进度文档；本清单不是验收完成声明。
