## 执行层规则

- 复用固定file helper和openat2目录FD；只接受枚举、root ID和相对路径，不接宿主绝对路径/命令。新增显式`files-mutate`动作，不将仅有upload的自定义根自动扩权；默认配置升级必须单独校验旧默认配置，不覆盖用户收紧的规则。
- 初始mkdir只创建一个明确叶目录，不递归创建祖先。初始copy/move/chmod只处理普通单链接文件；目录树操作在完整子树保护/清单实现后接入，不伪装成已完成。
- 计划绑定原版本、目标不存在、完整SHA/大小/普通权限/源与目标父目录身份。受保护名称、符号/硬链接、设备/FIFO、跨根逃逸或嵌套挂载仍拒绝。
- 默认不覆盖目标。copy先在目标私有目录完整复制校验/fsync，再NOREPLACE发布。move在此基础上将原文件原子移到源私有目录并保留，不直接unlink用户名称；非协作外部变更被隔离保留并报告Unknown，不销毁外部数据。
- mkdir同样先创建私有目录并持久化新inode，再原子发布。chmod仅作用于已打开且匹配计划的普通文件FD，模式仅0000–0777，不授予SUID/SGID。
- 操作UUID、不可逆owner和计划指纹永久绑定；终态重放只读回执，不重新执行。回执与上传分开保存在root私有子目录，不与旧上传UUID命名冲突。
- 回执阶段包括Preparing、DestinationApplying、SourceApplying、PermissionApplying、Completed、Aborted、Unknown。执行前fsync日志，执行后fsync受影响目录，再记结果；恢复只按保存的设备/inode、元数据、摘要判定，不自动补做原移动或权限变更。Unknown始终保留可调查对象，不自动清理/重试。
- 从源到目标的复制允许两个已批准根处于不同文件系统；move不是跨文件系统原子事务，不承诺原子双路径CAS。外部写入的临界竞态必须保留数据并明确Unknown。

目录项发布与文件内容持久化分别处理，依据Linux官方[renameat2/NOREPLACE语义](https://man7.org/linux/man-pages/man2/rename.2.html)、[fsync目录持久化要求](https://man7.org/linux/man-pages/man2/fsync.2.html)及[路径查找与并发重命名说明](https://docs.kernel.org/filesystems/path-lookup.html)。这些资料不等于本实现已通过实机验收。
