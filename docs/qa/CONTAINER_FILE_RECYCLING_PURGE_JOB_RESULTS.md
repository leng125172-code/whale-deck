## 固定历史结果与阶段语义

新增 ContainerRecyclePurgeJobResults，输出固定16字段：schemaVersion、intentId、jobId、sourceIntentId、sourceOperationId、stage、state、code、receiptState、reservationStarted、reservationRecorded、applyStarted、purgeApplied、sourceFenced、ownedFence、publishBarrier。只含不透明引用和历史事实；不输出容器/实例/路径、身份与登录、计划/确认签名、MAC、HDD摘要、属性、Root回执正文或凭据。

登记规划结束时保存规划摘要；确认创建独立执行任务后，原规划 Job 的结果不根据当前可变意图重新计算。Ready 只代表当时预检完成，不保证目前仍可确认。执行的开始预留、预留证明落库、Apply入口记录都在原有事务中保存自己的新摘要；修正开始预留事件误称 APPLYING 的文案为 RESERVING，没有把预留当成删除授权或增加 RPC。

预留入口记录、预留证明、删除入口记录是三个独立字段。Reserving 分“正在预留”和“已预留但尚未进入删除”；Applying 表示已经记录删除入口，结果仍待核实。缺少终态回执时 purgeApplied/fence 事实仍为 null，不把预留的保留原件结果当成最终未删除证据。Succeeded 必须有 Completed/已删除证明及预留、Apply入口记录；Canceled/Failed 的 Aborted 才能表示本操作未清理。

Unknown 仍为 Running 并保留保护，原件是否仍在不能从未知推断。Acknowledged 对应失败 Job 和保护释放，保持历史 null 事实；若原无回执 Unknown 在人工处置时取得晚到 Completed，则可展示该历史删除事实，仍不得把管理员处置标为成功任务。回执事实与当前文件状态分开，不改写原回收任务或规划摘要。

## 安全投影和页面

OperationService 对 list/detail 的两类 purge Job 专门调用白名单，不再进入成功任务的通用原 JSON 回退。投影限制4096字符/4层、精确字段数/名称/类型/唯一性、意图与确定性执行ID、原回收执行ID、阶段/Job状态/代码/回执及空值组合；无摘要、旧最小格式或不可信字段只返回 null。

Vue 实施同一16字段合同，拒绝额外/重复/缺失/强转/矛盾结果，降级提示不会原样展示私有 JSON。Jobs 页专属展示原来源、预留/Apply、回执和历史写入保护，明确预留不等于删除、入口记录不等于成功、HDD备份保留且当前尚未提供归档恢复入口。清理两类型不提供通用重试；Unknown 的原回执阶段或已验证 Unknown 摘要均隐藏取消按钮，仅指向专用文件入口核对。服务端原有禁止通用重试规则保持。
