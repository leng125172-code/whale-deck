## 页面与边界

- 容器文件列表的普通文件/目录提供“权限”入口；保护对象/特殊权限/正在进行的其他编辑禁用。四位普通mode、只读后台预检、原mode→目标mode、无变化确认、明确执行与明确取消。
- 仅请求ID/登记键留在sessionStorage，不保存路径、模式、planHash、Token或密码。刷新/导航/by-key接续原任务；丢确认先查询，不自动再确认；旧容器实例和过期计划不能确认。
- Unknown保留模式true/false/null、HDD可能存在/已验证/摘要的区别；显示元数据不包含文件内容。当前管理员可在文件页查询并处置历史，丢处置回复只查原结果，不冒充原登录、不重做chmod。
- 权限对话框与上传/编辑/历史/建目录/复制/移动共享界面锁。正常退出、401、初始化换人和降权清理权限引用；普通用户不发起权限/恢复请求。
- 客户端严格检查原命令、计划、终态、单调进度及HDD历史事实；JSON数组/对象不能凭正则隐式转换伪装成mode或版本。面向用户说明错误原因，原诊断码可通过提示查看。
