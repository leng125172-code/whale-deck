2026-10-17，开发中；尚未部署。现有生产运行时仍为036dfcb/Agent1.24。本轮目标是完整预览/编辑/版本冻结保存与覆盖上传共用HDD策略，不把独立执行模块或模拟UI签成完整功能，P0–P5的76项不缩减。

## 契约与边界

- 所有覆盖路径（直接上传、Worker暂存发布、后续编辑保存）必须先完成完整旧版本HDD复制、fsync、全SHA256复读与私有回执；保留源文件，随后原子发布。新建文件不存在旧版本，不伪造备份。
- root-only配置首次钉住实际HDD挂载点/文件系统UUID；内核mountinfo、只读udev设备缓存和旋转盘属性全部匹配。支持PrivateDevices沙箱，不读取原始块设备；缺失/错盘/只读/空间或历史上限失败关闭。现有配置保留，不静默重绑；先验证盘身份，再创建备份目录，避免HDD缺失时写OS盘。
- 备份目录与所有登记文件根分离、0700；数据0600，根以下openat2拒绝链接/跨挂载。Preparing中断不会自动重抄；完整数据但未完成元数据可经验证恢复，不再复制源文件。失败时只丢弃本操作的已验证暂存对象，原文件不变；不确定发布仍保持Unknown。
- 1.25能力files.hdd-versions；API/Worker写入口拒绝不支持的Agent。类型化凭据绑定操作ID、源版本、存储ID、旧大小、摘要和时间；覆盖完成缺失/不符凭据不得签成功。备份执行失败保留稳定错误码；备份可信性异常为Unknown，不重新发布。
- GET文件文本只读预览最多1MiB；完整流顺序、EOF、版本和SHA校验后严格UTF-8解码，拒绝NUL/无效UTF-8。独立元数据审计files.text-preview，不写正文。成功审计持久化前不返回文本，NoStore。
- 预览报告BOM及LF/CRLF/CR/混合换行。浏览器再次校验原始编码/大小/摘要；混合换行在正文修改后必须明确选择统一格式。保存复用原上传计划/确认/永久幂等任务/Worker；冻结打开时版本，不用刚刷新的版本覆盖旧编辑内容。正文不进浏览器存储。
- 当前共享文件根本身在HDD；同盘备份仅是版本留存，不是异盘冗余。六类数据库实际NVMe运行/HDD备份部署不移动、不重建。本轮不签回收站、目录复制、压缩解压、容器文件、租户隔离或完整恢复。
