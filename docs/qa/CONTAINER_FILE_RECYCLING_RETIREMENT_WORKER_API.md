专用 Worker 对计划、Reserve 与 Apply 在调用前及等待期间检查实时管理员、登录、取消、期限、来源签名和租约。调用后复核失败时，由下一次领取观察原执行结果。已进入宿主的接管只允许 Inspect 和 Discard 原执行，二者最多整理退役预留元数据。没有持久 Apply 入口时，Completed 回执不能标记本次执行成功。处置要求当前管理员、显式确认、准确版本与原执行观察结果。

HTTP 路由提供登记、按 ID 或幂等键查询、确认、取消、恢复查询和明确处置。现有 Cookie 管理员策略、BFF 同源和 CSRF 门禁覆盖写入口。请求 JSON 只接受所需字段和规范类型，拒绝重复字段及额外输入。响应投影只包含状态、业务 ID、到期与大小等必要事实。
