## 行为与保存路径

普通未受保护文件支持最多 1 MiB 的完整 UTF-8 编辑。读取复用原容器下载和完整大小/版本校验，再严格解码、核对完整字节摘要；无效 UTF-8、NUL、符号链接、受保护文件、无效版本及超限文件均拒绝进入编辑。空文件、中文、BOM 和双 BOM 不丢字节；LF/CRLF/CR 可显式选择，混合换行修改正文后必须选择统一格式。

容器位置单独保存完整容器 ID、原始纳秒启动实例和路径，不映射为宿主机 rootId。保存冻结打开时的文件版本，经既有管理员计划、二次确认、一次原始字节发送、SQL/Worker/Agent/Root/HDD 发布流程完成；没有新的直接写文件通道。预检发现外部版本变化时零计划/零内容上传，保留原私有草稿供重新编辑与合并，不把新版本偷偷当作覆盖前提。

取消覆盖确认时没有登记或发送文件，可返回原草稿；未保存编辑关闭时使用该编辑器自己的继续/放弃对话框。主体/权限/容器/实例/目录变化或卸载同步清除并取消请求，迟到下载不能重新填入旧内容；相同用户资料刷新不会误清空编辑器。上传与编辑互斥，私有草稿只在内存中，不进入浏览器持久存储。
