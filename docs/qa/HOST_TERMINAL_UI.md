## 共享功能/视觉检查清单（实现前）

| 行为/承诺 | 功能检查 | 视觉状态及证据 |
| --- | --- | --- |
| 管理员入口、默认不连接 | 菜单/路由权限；进入页面不申请票据；普通用户拒绝 | 初始视口、受限非root身份说明、开始按钮可见 |
| 明确确认后连接 | 取消不写；确认后CSRF/幂等申请；票据只在WS首帧，不入URL或存储 | 确认框、准备/连接/已连接状态；桌面和320px |
| 实际交互终端 | 输入/输出、UTF-8/二进制、有界粘贴、resize与退出码 | 短/长行、中文、光标、滚动、尺寸变化 |
| 断开与重新连接 | 显式关闭/页面离开关闭；不自动重开已消费票据；重新连接新会话 | 已关闭/异常/退出码提示、按钮状态 |
| 清屏与主题 | 清屏只作用本地；主题改变不新建会话 | 明暗两套终端颜色、清屏后及新输出 |
| 读屏按需切换 | 默认标准输入，开启读屏后原生IME组合提交，关闭回标准输入；不新建会话 | 可见开关、读屏可访问性列表及普通终端文字 |
| 权限和故障 | 401/403/撤权清正文并终止；503/票据迟到/WS失败不假成功 | 错误/追踪号、失权不显示旧输出 |
| 响应式与无障碍 | 320/390/1045/1440/1920，无页面横向溢出；键盘可用 | 独立截图检查按钮/终端/状态区域未被裁切，不只看数字 |
| 有界客户端/清理 | 输出队列、输入/消息限制；卸载/失权移除监听/计时器/终端 | 高密度输出/错误状态；浏览器及本地服务清理记录 |

探索场景至少包括：确认等待期间离开/权限变化、连接中快速调整窗口、输出时切主题/清屏、异常断线后人工重新连接。不把fixture浏览器证据称为生产身份端到端；真实OIDC/已部署UI验收另行记录。

## 实现与本地验收

- 懒加载管理员路由 `/host/terminal`，xterm 6.0.0 / FitAddon 0.11.0精确锁定；标准输入为默认，读屏可选。实际业务调用CSRF、一次性票据、同源WebSocket首帧token、尺寸同步、退出码与关闭端点；没有浏览器Token存储或自动重连。
- 客户端16 KiB单次输入/4 KiB帧/64 KiB待发/1 MiB待渲染预算、1000行回滚；迟到许可、取消与离开、协议错误、断线和失权清理。输出交给终端解析而不是HTML；短时票据不进入URL。
- 页面自有确认框替代全局MessageBox关闭，避免离开时误关其他页面弹窗。HTTP/IP缺少`crypto.randomUUID`时使用`crypto.getRandomValues`生成UUIDv4，不使用Math.random。
- 163前端单元测试、类型、lint、格式检查及生产构建通过。终端18项 + 原任务SSE 4项浏览器回归通过，另11项私有通知/4项限流通过，共37项；所有这些浏览器用例使用fixture，不能称为真实宿主执行证据。
- 中文原生IME组合、修改/取消/提交与emoji、读屏开关完整往返、超长中文拒绝、浏览器返回关闭确认框、离开活会话、手动重连、退出码7、异常和撤权均实际操作验证。320/390/1045/1440/1920两主题，以及320/390×560短视口检查必需区域边界，无页面横向溢出。
- 独立视觉查看了桌面确认/连接、390×844触控确认/连接/暗色及500×837原生窗口启动布局；32–48帧滚动输出后切主题/清屏/继续输入探索通过。截图在`deploy/artifacts/terminal-*.png`，不纳入Git。初次截图捕获主题/对话过渡，稳定后重拍并检查实际文字对比度，未把过渡态当成最终视觉结果。
- 首版强制读屏导致普通insertText输入丢失，已改默认标准输入、读屏显式开启；不是删除中文断言规避问题。首次覆盖测试13项通过后继续扩展，最新37项通过。
- GLM Flash经唯一router只读盘点四份UI文件，GPT复核并补测试。首轮因禁止shell读取而无结果：11041输入/0缓存/377输出、24407ms；放开仅这四文件的只读读取后成功：179112输入/141824缓存/2946输出、143653ms。失败1/重试1、费用未返回。权限和生产验收未委派。

## 真实浏览器验收准备

`deploy/validation/ephemeral_browser_user.py`只用于工作站验收：调用方在内存生成随机临时用户名/密码，通过SSH私有stdin传入，不使用参数/环境/日志传递；只返回ready/cleanup元数据。脚本仅创建指定随机前缀账号，stdin关闭、600秒超时或TERM/HUP/INT后精确删除本账号。正式验证仍需实际访问登录页、通过Authentik表单和页面建立WS，不注入Cookie或替换API。

当前记录尚未证明本增量已在工作站部署，也未证明生产身份浏览器UI通过。P1-11完整范围还包含容器Exec/文件传输、团队隔离和保留清理，不能因此标完成。
