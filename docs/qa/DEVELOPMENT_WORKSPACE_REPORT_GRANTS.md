# 开发空间报告委派授权

2026-11-09，代码 `1931f19d`，迁移 `20261109100356_WorkspaceReportGrants`。

管理员可对已有报告记录的工作空间，通过 `GET/PUT /api/v1/development/workspaces/{workspaceId}/report-access/{groupId}` 查询或设置报告读取授权。组标识使用 Authentik UUID。PUT 需要 BFF 同源和 CSRF 校验、当前管理员权限，以及 `enabled` 与 `expectedVersion`。初次授权使用版本 0，后续变更使用当前版本。撤销保留版本，过时提交不能复活授权。变更与审计同事务，带授权历史的降级被拒绝。

报告下载支持当前管理员和当前属于已授权组的开发者。下载前、读回正文后以及准备审计后均检查当前身份、登录和空间授权。该权限限报告读取。实时 Authentik 解析使用组主键，组显示名即使形似 UUID 也不能代替主键。
