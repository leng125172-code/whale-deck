## 写入与中断行为

1. 计划读取并核验历史完整归档，同时扫描目标完整树；计划不写目标或创建新捕获。
2. 在 root 私有暂存目录解包历史内容，验证全字节、成员、模式、当前目标根属主和纳秒时间。
3. 为目标建立独立 `Overwrite` HDD 捕获，完整校验归档后再继续。捕获 ID 为当前操作 ID，资源 owner 为当前操作，不冒充历史捕获 owner。
4. 慢速 HDD 操作之后重新校验输入、暂存、目标完整清单、父目录、暂存目录绑定及根策略，持有已有 namespace 写锁与捕获锁。
5. 持久记录 swap intent，再使用 `renameat2(RENAME_EXCHANGE)` 原子交换两目录。旧目录整体留在 root 私有暂存位置，不删除，不逐项覆盖，不先挖空目标。
6. 只有新目录 identity/全树证明、旧原件 identity/全树证明、HDD 捕获完整证明均通过，才记 Completed。取消发生在已交换之后也按实际证明识别 Completed，不能谎称未写入。

恢复只观察，不重新捕获、不解包、不再交换、不删除或自动回滚。交换意图之前目标不变时可记 Aborted；意图已写但效果不明、父路径变化或证明不符时记 Unknown。已发生交换且两边与归档均匹配时可以确认 Completed。Unknown 不会因普通重放自动尝试修复。
