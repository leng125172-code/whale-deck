# 文件列表帧预算与顶栏内容区域

2026-10-17，开发中；不得作为完整 P0–P5 或文件管理签收。

## 验收清单

- 普通文件及目录树列表：合法 255 字节、含大量双引号和 Unicode 的名称；真实 Linux 文件系统枚举，经实际 emit 编码每页不超过 64 KiB。分页游标取最后实际返回项，不跳项、不重复，版本稳定；take=1、100 和空页均检查。
- 顶栏：320/390/1440px、明暗、13/99+ 未读和 50 任务；有、无经典垂直滚动条，逐按钮和角标检查内容区域边界及间距。不是仅检查 scrollWidth。
- 实际交互：搜索开启/关闭、导航开启/关闭、主题往返、任务/通知抽屉开启/关闭；鼠标与键盘焦点可用。
- 独立目测：最窄宽度的初始、滚动后及主题切换状态截图；检查主题开关、角标、版本号是否裁切或覆盖。补常规桌面及原生窗口检查。
- 探索：缩放窗口跨断点、极长搜索词/空结果，确认不引入横向溢出或丢失动作。
