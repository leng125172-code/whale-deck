## 页面行为

- 管理员在容器文件普通文件/目录上选择移动，输入不存在的相对目标路径；先异步预检，再确认原完整计划。源文件转存私有原件区后移除原路径，与复制保留原路径的提示明确区分。
- 计划/执行任务分别展示，目标发布、源路径移除、原件留存独立显示已确认/未发生/尚未核实。缺失字段、错误OperationKind、缺原件的成功或反转已知事实均拒绝；未知不变成false或成功。
- 原请求/确认丢回复后仅查询同一引用，刷新恢复不新登记、不自动确认。实例变化、过期、权限失效阻止确认；进行中取消二次确认，完成不反向撤销。
- Unknown进入当前管理员异常处置页，显示三项事实与私有数据不确定性；明确确认后封闭原执行，再查询持久回执。处置丢回复先查询原结果，禁止自动重发确认或删除历史。
- 移动与已有上传/编辑/历史恢复/复制/新建目录前端互锁，后台仍依赖真实SQL全局屏障。独立sessionStorage只保存subject/容器ID/幂等key/意图ID，不存路径、确认token或内容；退出/降权/换用户清除引用。
- 共用Element Plus明暗变量和有界弹窗样式：长路径换行，内容区滚动、底部按钮保留；新增入口不恢复图标折叠导航或改变顶栏。
