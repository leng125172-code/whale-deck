# 归档退役文件页和 Jobs

2026-11-09，候选 `0cb8878d`。文件页支持从已核实的归档摘要选择来源或输入归档意图 ID，明确填写保留天数，读取最早退役时间与确认期限，再逐次确认执行或取消。登记响应中断后，用当前登录、容器和原幂等键查询。仅在查询返回未找到后允许用户手动用原键重登。确认票据只保留在已打开的页面内存中，关闭、退出和权限变化会清理相应状态。

Jobs 显示经过服务端与浏览器校验的 15 字段白名单摘要。规划任务保留原结论，执行任务区分预留、执行入口、共享保护和三态删除证明。已有任务缺少安全摘要时显示待核实。Jobs 可打开原退役任务，Unknown 需从专用恢复接口重新核实，再显式处置。退役任务停用通用取消和重试。普通取消经原任务的实时授权和绑定检查。
