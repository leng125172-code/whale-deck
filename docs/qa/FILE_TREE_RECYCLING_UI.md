## 测试前功能与视觉清单

- 仅管理员与具备明确tree-trash源授权的目录展示回收动作；普通用户直接/刷新含任务引用时不得发文件请求。
- 打开只展示源；生成计划仅扫描、确认才产生独立执行。计划数量/大小可读，使用统一GiB/MiB单位；长中文路径/UUID/摘要不撑宽页面。
- 持久幂等键在POST前保存；刷新与丢响应只GET原引用，确认响应未知时禁用再次确认。完成任务显示源移除、原件保留和独立HDD证明，不声称当前文件系统不再变化。
- 取消二次确认；Unknown状态明确副作用未知，原登录可显式接受、不重复Apply；跨登录使用现有当前管理员恢复界面的新第八类型。
- 目录捕获记录按登记根或完整路径查询；上一页/下一页、刷新范围、空状态、错误与证明展开/收起均可操作。记录仅表示历史验证，不冒充源已删除或当前磁盘健康。
- 320/1045/1440px明暗主题：首屏、待确认、成功、Unknown、密集长路径/摘要记录各自独立截图/布局检查。所有对话框主动作可达，正常内容区允许纵向滚动，页面不得出现横向溢出。
- 额外探索：计划/捕获证明被替换；丢登记/确认响应；查询返回403/404/503；关闭对话框后迟到响应；身份改变清空界面；未授权根与普通账号。

自动浏览器脚本以本机生产预览5175运行；最终还须通过本地Playwright技能进行独立人工式输入/视觉检查并记录截图和清理。安装态与真实身份/磁盘证据单独补充。
