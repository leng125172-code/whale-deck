## 已实现

  原始请求、完整计划、确认执行分别 MAC 绑定；规划/执行双 Job、事件、Outbox 和哈希化审计同事务落库。
  原路径和计划只进入受控意图，不进入通用 Job/审计；没有文件字节、登录 token 或数据库密码。
- 十二项检查约束、受限双 Job 外键、并发版本、稳定查询索引及唯一执行/租约/发布保护。
  SQL guard 保持请求、已生成计划、确认执行、Root 开始标记和终态不可变；不允许删除永久意图。
  存在历史时明确阻止降级丢表，不为 dev 自动回滚。
- 仓储以共享 advisory transaction `41307341` 保护登记、并发确认、取消、90 秒租约、六秒续租、发布前标记与结果。
  原确认重试只返回原执行；规划取消可直接封闭只读规划，执行取消必须得到 Root 原操作栅栏。
  Unknown 保留发布保护与私有内容可能存在的事实，现任管理员接管保留原 actor/owner/执行 ID 和 Root 回执。
- 复制、上传、建目录和宿主路径的双向互斥。旧仓储已加入复制范围与预算检查；数据库触发器保护旧代码/直接 SQL 的发布入口。
  租约过期不会释放保护，旧租约不能提交新终态，后继 Worker 只能观察/封闭原 Root ID。
- 独立 Worker 已注册；通用 Outbox 消费器排除复制消息，通用取消正确分流，通用 Job 重试明确拒绝两个复制类型。
- 管理员 REST：异步登记、按 ID/原 key 查询、确认、取消、Unknown 查询及接管。
  写入口要求唯一且匹配的规范 UUID Header，保持全局 Cookie/CSRF/Origin 规则；202 表示接收，不能当作复制成功。
  现有 Job 查询/SSE 继续承载两阶段进度；Agent 线协议仍为候选 1.45，不再增加版本。
