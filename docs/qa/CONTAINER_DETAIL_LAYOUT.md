# 容器详情列宽修复

本批只修改容器详情布局，不更改 Docker 操作、权限、环境变量值、采样、数据库或 Agent 协议。目录归档引擎的在研文件不包含在本批发布中。

## 原因和修正

- 原双列 descriptions 在“资源限制”后剩余半行，后续声明整行的环境变量被 Element Plus 限制到剩余一列；自动表格布局又按长配置名称挤压其他值列，导致状态、网络 I/O 被切成竖排。
- 镜像独立整行；状态、保护级别、CPU、内存、网络/磁盘 I/O、进程数、重启策略保持桌面成对展示，两侧值列等宽。
- 资源限制与可变长度的环境变量名、命令、Entrypoint、健康检查使用独立单列 descriptions，不再和指标表共享列宽。固定表格布局、96px 标签和安全折行均只作用于容器详情，小屏继续单列展示。

## 本地证据

- lint、Vue 类型检查及生产构建通过；34文件/265前端单元测试通过。
- 10项新增生产预览布局测试通过：320/760/1045/1046/1440px，明暗主题；超长无空格环境变量、状态/I/O/资源限制最小宽度与最大行高、双列等宽、整行配置、无详情/整页横向溢出、0管理写请求及0页面错误。截图目测1440暗主题指标正常。
- 12项既有关联资源浏览器回归通过，共22项。关联资源套件使用原开发测试入口，新详情10项使用生产预览入口，不混称全部生产构建或真实 Docker 验收。
