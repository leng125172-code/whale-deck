## 阶段与失败恢复

14 条 CHECK、状态守卫及部分唯一索引分别约束规划、确认、预留、Apply、观察和明确处置。Reserve 可以早于到期时间。Apply 须先有已记录的同执行 Reserved 回执，并达到计划的捕获年龄，数据库拒绝同一次更新写入 Reserved 并进入 Apply。Unknown 保留共享围栏、原回执和 nullable 归属。只有明确处置才能从 Unknown 释放共享围栏。原回执与结果仍然未知时，同归档继续受到唯一消费保护。非空退役表拒绝降级，历史不会随版本操作被删除。

沿用 41307341 事务级写锁。围栏在退役表、宿主路径锁和现有容器写入器合计 17 个入口生效。保守的全局排他覆盖跨容器共享宿主目录的别名。已有写入器先查询退役围栏并走原等待路径，SQL 触发器封住绕过仓储的写入。退役意图计入共享全局和按管理员限额。
