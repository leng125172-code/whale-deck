## 已实现边界

- FD-only的TAR/PAX、TAR.GZ生成、完整索引校验与私有目录解包，不接受宿主路径、不调用shell、不使用extractall、不发布/覆盖/删除源目录。归档来源必须通过既有登记根list+download及完整树manifest复核；每个文件完整读取/hash，读取前后版本及父FD/叶名称复核，结束再次核对全树。
- 10000项/32层/16GiB总内容，归档文件最大17GiB，PAX每项16KiB/总16MiB、索引16MiB、600秒与取消限制。头先验收类型/长度，不让通用tar扩展处理器先读取稀疏或超大PAX数据。只使用标准库公开的固定512字节 `TarInfo.frombuf`/`tobuf`，自有有界PAX/数据流处理。
- 拒绝路径穿越/绝对路径/反斜线/受保护配置、链接/硬链接/设备/FIFO/稀疏/全局扩展、重复项/文件父目录冲突、非法UTF-8、坏头/截断/CRC及非零尾随数据。不能把部分文件或受保护子树静默跳过后声称完整归档。
- 普通权限位和纳秒mtime保留；危险setuid/setgid/sticky位不应用，解包文件的uid/gid来自可信目标策略，不采信上传包的owner。顶层解包目录始终root/0700，直到后续单独发布栅栏；只有已预扫描且签名绑定的计划才应进入未来公共写入口。
- 私有目标须为空，文件O_EXCL创建，既有目标不覆盖；解包后独立重读磁盘文件并核对全量成员/哈希/模式/属主/mtime。错误/取消保留私有部分对象，不自动重做或清理，不承诺全树MVCC或独立于调用方资源锁的原子发布。
- HDD留存复用既有UUID/挂载/udev/rotational/只读策略与容量保留；独立私有子目录，不混入普通单文件版本元数据。保存源manifest、内容/归档摘要和Preparing/Ready/Verified事实；原目录完全不修改。
- 中断未发布的.partial不再复制或自动晋升；仅已发布、原inode/完整hash/manifest吻合的归档允许补写Verified回执。配额只阻止新捕获，不阻止核对既有回执；不自动删除旧版本。

## 初轮问题与修正

- 根权限撤销异常路径出现未关闭GzipFile ResourceWarning。改为在授权范围内使用无文件句柄的zlib流式gzip编码器；失败不在析构器里补写footer，最终警告即错误重跑通过。
- 实盘探针初轮中文测试名称编码256字节，超过单组件255限制，启动阶段OSError；尚未开始HDD捕获。只读核对两个唯一自有root/0700空目录后使用确切绝对路径rmdir，未递归删除；改为预先断言长度、238字节名称和可追踪夹具标识，最终实盘通过并清理。
- 新增旧历史交互测试初轮调用了要求root拥有源码模块的安装态加载器；公开scratch源码属于user，因此被正确拒绝FILES_MODULE_UNSAFE。改为与旧单元测试一致的明确类级调用，仅验证命名空间互不误读；没有放宽生产模块权限，也不把该回归称作安装态加载器证明。
