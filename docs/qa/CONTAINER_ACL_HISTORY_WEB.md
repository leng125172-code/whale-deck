## 权威来源、业务与安全

每个当前文件/目录有独立“ACL历史”入口，只读查询当前CID/启动实例/规范非空准确路径；不引入可绕过当前容器保护的全局宿主目录。两路GET为`/api/v1/containers/{containerId}/files/acls/history`和其`/{captureId}`，与现有ACL修改意图路由互不冲突。没有恢复/写入/内容流接口或未实现按钮。

新增Application `ContainerAclHistoryService`复用实时FileManagement管理员授权与原登录registry：RPC前、输出核验后和审计完成后都重新检查；当前身份与原登录不成立不返回ACL。SDK继续独立1.52能力/全请求签名、现有资源注册/核心与共享挂载保护，API/Worker不接Docker socket。Controller只负责身份与传输，严格拒绝未知、重复、大小写别名或无效类型query；模型绑定错误不回显输入，响应NoStore。

历史权威仍在实际HDD元数据，未新增或伪造SQL历史缓存/重复ACL账户。持久化读取审计复用现有`audit_events`、EF仓储与事务提交，无schema变化/迁移或新包。新增两项固定审计action为`containers.files.acl-history-list`和`containers.files.acl-history-read`，只记原主体/Trace、路径和实例hash、库存version或ACL元数据digest；不记ACL正文、原plan/owner、捕获正文、宿主路径或key，文件字节size/sha256为null。审计失败不返回私密内容；审计后的撤权仍拒绝回应，已验证/读取审计不冒充“用户已收到”或恢复成功。

业务层再次校验位置、摘要、原实例、条目/模式及有界库存页；将数组冻结后再await审计，外部共享数组变化不能替换已核验结果。客户端断连token直达gateway，未完成读取不落Validated审计；本轮对此的HTTP测试使用可取消Agent夹具，尚非运行态新RPC中断验收。

## 实际Vue功能

原生Element Plus弹窗按准确路径分页、继续扫描和重新读取；用户选择捕获后才读取完整原access/default ACL。展示留存时间、原启动实例、捕获ID/摘要、原普通模式、数值ID/权限及经mask的有效权限，显式0、空default与模式0000不会当缺失。清楚标明历史原件不代表当前权限；无“恢复”空按钮。

TypeScript逐字段拒绝额外/缺失/错误类型、跨容器/实例/路径、错摘要/被替换摘要、重复/不前进游标、过预算、模式与ACL不一致；不对数组或数字作字符串强制转换。只有成功的完整空页显示暂无；空部分页仍可继续扫描。续页版本变化清空旧序列，重新读取从空cursor/version开始，错误不冒充空历史。

所有请求用AbortController与generation丢弃迟到响应；关闭、换目标/目录/身份、管理员权限消失、隐藏页面及卸载都清空内存。401/403清面板，不自动发起恢复或重试查询；异常只显示中文固定提示，不回显上游私密错误。历史/ACL快照不写local/session storage。列表累计最多1000项；库存扫描/invalid统计仍是全局库存，不声称按路径统计隔离。

紧凑记录卡、主题变量、长路径/摘要换行、正文滚动及固定可换行页脚支持320×600和桌面明暗主题，关闭/取消读取始终可操作。原文件管理和ACL修改页的行为保留，相关页面回归单列。
