## 实现

- 精确64位容器ID和PID+启动实例绑定；pidfd、进程启动ticks、cgroup、PID/mount namespace及根FD重复核验。
- 复用已安装容器终端的核心注册表/标签保护及隔离、挂载白名单。另核对实际挂载inode/device、核心挂载重叠、local具名卷driver/options/mountpoint；不接收任意宿主路径、命令或shell。
- openat2强制相对路径、禁止符号链接/穿越；虚拟目录、私有文件及硬链接/特殊文件不能成为下载内容。单页最多100项/48KiB，扫描最多250000项/5秒。
