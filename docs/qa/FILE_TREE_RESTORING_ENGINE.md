# HDD目录恢复引擎：源码在研，尚无公开入口

## 实现与完整范围

新增独立目录恢复计划域、回执命名空间和暂存后缀，从已验证的私有HDD目录归档恢复到不存在的新目录（包括原目录已不存在时的原路径）。复用已验证的有界流式解包、完整落盘核验、NO_REPLACE发布和只观察恢复，不把HDD归档注册为浏览器可读根，不接受宿主任意路径或命令。

捕获ID、原始资源owner绑定、原源路径/版本、清单SHA和Trash/Overwrite类型全部必须与旧Root捕获事实一致；当前操作owner可以不同，仅表示新操作，不能被当成原登录模拟。未来BFF仍必须对当前操作者和该原始资源单独授权，这不是已实现的身份鉴权证明。恢复要求独立files-tree-restore授权；注册表仅允许识别该标签，默认注册表未升级、CLI/RPC/安装器未开放新动作。

HDD读取使用只打开已存在捕获的模式：不存在的记录不分配锁/目录项，不因只读计划修补Ready回执；完整归档/清单、存储身份、同inode/版本和根策略在读取前后复核。持有同捕获锁跨越解包，阻止未来并发清理替换输入。目标UID/GID只来自可信根策略，危险权限位不恢复。恢复回执与普通解压、私有暂存名称隔离，原始归档和旧源均保留。

本批仅是完整目录回收/恢复中的“从已验证捕获恢复到不存在目标”的内部步骤；目录回收、覆盖前目标留存/隔离、彻底删除、长期清理和其Agent RPC/BFF/SQL/Worker/审计/WebUI仍待继续。不以拒绝覆盖取代最终所需的覆盖恢复流程，也不签完P2-03/P2-04或全部76项。
