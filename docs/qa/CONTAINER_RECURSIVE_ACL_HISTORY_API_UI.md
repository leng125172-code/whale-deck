## 业务和权限

- 新Application历史服务使用权威身份源和有效BFF登录绑定，在读取前、结果冻结后和审计保存后各复核当前权限；匿名/普通用户、撤权/退出后的迟到结果不能返回私有前像。SDK读取不走SQL历史副本，不把已缓存元数据作为恢复授权。
- 返回结果在任何后续await前冻结：列表数组、逐项数组及每项access/default ACL均独立只读复制。审计失败、上游结果无法核实、调用取消均失败关闭，不转成空历史成功。
- 独立审计接口/实际EF实现写现有audit_events，无Schema变更、无EnsureCreated或本地密码/人类资料副本。每个List记录路径/实例/游标摘要、库存版本、页预算和扫描/返回数量；每个Read记录路径/实例/捕获摘要、元数据摘要、offset/take/返回数及完成标志，不保存原ACL、私有owner/plan、源inode或原路径。实际部署后的PostgreSQL写入仍须取得证据。
- 管理员只读GET `/files/recursive-acls/history` 与 `/{captureId}`，严格限定查询键、大小写、单值；Read必须显式给offset/take及选定摘要，不把缺offset当成0。重复、额外/类型无效、无当前实例/非空路径请求均拒绝，错误不回显原输入。保留no-store、Cookie/BFF、GET-only和资源/核心保护，POST不提供恢复动作。
- MaintenanceHost新增仅上述两个GET的35秒有界代理，保留原Host头及0请求体；不放宽其它API、Authentik或写入路由。新路由尚未安装，不由本机预览代替维护入口实测。

## 页面与数据约束

目录新增“递归ACL历史”入口，原计划摘要列表与逐项前像详情分开；完整计划/变更数量明确不代表原执行完成/实际修改数量。显示捕获/清单摘要、原启动实例、原模式及两ACL/有效权限，保留命名ID0、权限0、空default及零变更历史。当前没有恢复按钮或写接口。

库存可读取到后端10000份上限，同时每屏最多25张卡，已读记录可前后翻页；目录版本变化必须重新读。逐项详情只保留当前页和offset回溯栈，以选定捕获的完整摘要验证每页，严格核对位置、连续进度、末页根目录和深度/UTF8顺序；不把当前统一file/directory ACL套作历史。API JSON转义最多约六倍，浏览器另限1MiB响应，原生/协议128KiB上限不变；所有路径仍受字节及分段约束。

关闭/取消、主体或管理员身份变化、容器/实例/目录切换、父级busy、页面隐藏和卸载均同步清空并取消读取，generation令牌丢弃晚到结果。401/403清空关闭，404/409/412丢弃不再可信的选择，429/503提示手动重试；失败不显示“暂无历史”。布局复用Element Plus主题变量，320×600明暗与reduced-motion兼容。
