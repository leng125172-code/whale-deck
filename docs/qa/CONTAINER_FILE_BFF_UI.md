## 安全与持久化边界

只读专用路由`/api/v1/containers/{containerId}/files/{target|entries|entry|download}`；Controller只做传输。Application沿用当前管理员复核，严格容器ID/启动实例/UTF-8路径/分页与输出校验。不存在host rootId、任意命令、写入或恢复兼容分支。

审计复用已有不可变AuditEvent，无schema变更；记录主体、容器ID、trace、动作、结果、路径/实例的SHA及版本/大小/内容摘要，不含原路径/内容/环境或Cookie。下载Started前不发送内容；Validated在完整RPC正常EOF、摘要与权限/Cookie复核后落库，才交付end；取消/异常记Incomplete，不声称客户端已接收。

初次构建触发CA1870，改用缓存SearchValues，不降分析器；随后using位置错误已修正。GLM机械定位调用本机路由器报null-valued expression，未收到模型结果/usage，未声称其已审查；GPT接手实现与复核。
