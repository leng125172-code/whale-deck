## REST 契约

前缀 `/api/v1/files/tree-packings`；所有入口只允许当前管理员。

- `POST /`：`{ source, expectedVersion, target, format }`，单个规范 UUID `Idempotency-Key`，返回 202 和持久计划 Job。
- `GET /{id}`、`GET /by-key/{key}`：原用户及原登录绑定只读查询，不启动任务。
- `POST /{id}/confirm`：`{ planHash, confirmed, version }`，幂等键等于意图 ID；返回 202 和独立执行 Job。
- `POST /{id}/cancel`、`POST /{id}/acknowledge`：取消/原登录未知结果明确接受；仍需对应幂等键，确认接口带版本及显式确认。
- `GET /{id}/download?expectedVersion=...`：完成回执专用归档流，禁止 Range。使用当前管理员身份，可重新登录或交接后下载，不冒用旧登录。Agent 用旧 opaque owner 绑定原回执，同时重新验证目标根策略、身份、版本和完整摘要。

Cookie 写请求沿用全局 CSRF/Origin 验证；下载每 6 秒校验登录和权限，完成时再次校验。服务核对精确目标名称、大小、版本、分块序号及全量摘要，记录当前下载者的开始/结束审计。HTTP 暂扣最后一块，只有 RPC 完整结束、权限和最终持久审计成功才送出；普通文件下载仍限制为 1 GiB。
