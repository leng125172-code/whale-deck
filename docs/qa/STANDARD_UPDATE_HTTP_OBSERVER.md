# 标准更新 HTTP 观察器：有界采样与原失败保留

2026-11-11。新增只读 `standard_update_http_observer.py`，不执行更新、不登录、不修改资源、不读取凭据，不重试失败请求或记录响应正文/Location/Cookie。

- 固定四入口串行采样，每轮结束至少等待1.5秒；受 API 120/min 限流的 system/status 最多约40/min。其余为独立健康、静态构建信息和身份入口，不以总请求数替代各入口预算。
- 连接预算2秒、响应墙钟预算8秒；后者覆盖现有5秒代理活动时限及2秒状态探测，慢速分块响应也受限。分别记录连接阶段、响应阶段、耗时、错误类型和有界 Retry-After。
- 8秒内可达与原3秒阈值独立报告；超过3秒仍使 `threeSecondPassed=false`。保留全部429、连接失败、超时、过大响应和后台观察线程失败，不以扩大预算追认原失败。
- 503须为带平台标识的维护HTML。身份根入口实际返回302；仅8081根路径到默认认证相对路径、无返回参数或仅返回根路径的精确Location可认可。不跟随跳转，不认可外域、其他路径、额外参数或其他3xx；这只证明入口响应，不证明登录流程。
