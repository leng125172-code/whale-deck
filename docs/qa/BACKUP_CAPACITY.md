# 备份容量预警验收清单

本阶段源码尚未发布。固定 HDD 目标容量使用新的签名 UDS RPC（backups.capacity），root helper 只接受无参数读操作，拒绝符号链接或目标与 HDD 基目录不在同一文件系统；缓存 30 秒，未知/旧样本不得误报为健康。数据库与普通应用策略沿用同一批准 HDD 目标，告警由策略自动维护，不能在通用告警规则入口改写。

功能/界面清单：策略容量预警与临界级别、实际使用率/可用空间/阈值与样本时间、容量未知、去重、升级重新确认、未来静默保留/到期激活、恢复/策略禁用、只读规则编辑提示、确认/静默操作、刷新、空/503/403与迟到响应。每个控制均须正常点击；窄屏表格只允许内部滚动。截图覆盖 320/390/1045/1440px 明暗主题与触发/未知/恢复等状态；异常探索包括失效权限期间的刷新和已恢复告警再操作。

容量百分比阈值和状态转换先做纯方法测试，再验证工作站实际容量、策略到规则接线、生产权限、OpenAPI 和 PostgreSQL 历史。不能为了触发预警填满生产 HDD，也不能把合成容量样本当成生产磁盘真的满了。SIGKILL/断电演练需有独立且精确绑定的临时归档任务，不对主机断电或强杀核心服务。
