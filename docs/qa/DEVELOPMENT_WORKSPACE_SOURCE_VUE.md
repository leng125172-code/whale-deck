# 开发空间归档导入页面

2026-11-09，代码 `3f2ab1d5`。空间详情的源码导入页支持选择 ZIP、tar 和 tar.gz，按 1 MiB 分块计算 SHA-256 和上传。页面刷新后从服务器读取当前导入与已接收偏移。重新选择的归档须与原格式、大小和摘要一致。首次发布前，所有者可以核对文件数、展开大小、内容摘要和计划摘要，再显式确认。取消和暂存、发布、清理状态均在页面反馈。

页面校验回执的空间、导入、归档和计划绑定。服务器响应不明时暂停提交，由刷新核对状态。撤权或失去资源可见性时清除页面上的归档和计划。浏览器在当前页面内存中保留文件引用和待确认请求，跨刷新恢复由服务器提供，用户需要重新选择原文件。

## 实际验证

- 用 Chrome 打开生产构建，连接真实回环 Kestrel、PostgreSQL 和运行中的 `WorkspaceSourceWorker`。两次在服务器已提交后丢弃浏览器响应，分别覆盖第一个分块与发布确认。刷新后只上传剩余块，浏览器记录两个分块和一次发布确认，Worker 夹具记录一次暂存和一次发布，数据库确认租约释放及密文块清理。另一个已登录主体无法进入源码导入页。该链路的身份与 Agent 使用隔离测试夹具，标准 Agent 1.69 另有离线 KVM 验收。[标准 Agent 与持久化流程](DEVELOPMENT_WORKSPACE_SOURCE_WORKFLOW.md)
- 生产预览浏览器验证无 `crypto.randomUUID` 和 `crypto.subtle` 时仍可生成导入 ID、核对归档、续传和确认。不同摘要的同大小文件、跨空间回执与撤权均被拒绝或清除。另验证暂存后取消、桌面及 375 像素暗色窄屏。首轮 Playwright 点击了 Element Plus 视觉隐藏的复选框输入，改为点击可见标签后复验通过。
- 真实 PostgreSQL 套件验证当前导入读取、空结果、非所有者拒绝与最新终态。初次类型检查发现浏览器计时器与 Node 类型冲突，且项目目标缺少 Object.hasOwn。修正后生产构建、格式、lint、1469 项前端单测、11 项定向浏览器用例及 8 项范围基线通过。
