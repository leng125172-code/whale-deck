# 目录解压：内部发布引擎与验收边界

## 2026-10-19 源码实现，尚未安装

新增独立 `FileTreeUnpacking`：登记普通归档文件 → 完整检查 → 私有目录解包 → 全量核验 → 新目录 NO_REPLACE 发布。使用独立 `whaledeck-tree-unpacking-v1` 指纹域和 `tree-unpacking` 回执目录，不解释旧复制、移动、压缩或文件回收计划。

**本批不是完整解压功能交付。** 没有 CLI/helper 调度、Agent RPC、BFF/数据库任务、Worker、WebUI 或线上部署；线上仍为 abef670/RPC1.30。驱动只识别新增授权动作的合法名称，未扩大安装态或默认登记根的权限。P2-03/P2-04 和全部76项仍为进行中。

## 行为与约束

- 归档仅从已登记来源读取，要求 list/download/archive/tree-unpack；目标独立要求 mutate/upload/archive/tree-unpack。普通复制或压缩授权不能替代解压授权。源版本、双方策略摘要、归档全 SHA/长度、内容摘要/条目/展开字节及目标父设备/inode绑定计划；不把完整清单放进32KiB回执或未来 RPC JSON 帧。
- 支持 TAR/TAR.GZ；来源扩展名不作为格式或权限证明。PAX 与有界 GNU 长文件名均走相同保护规则；不使用 extractall、不接受符号/硬链接、设备/FIFO/sparse、越界路径、受保护后代或重复/冲突成员。ZIP 等其他格式仍待实现，不以本批排除最终范围。
- 最多10000项、32层、16GiB展开数据、17GiB归档；元数据/放大率/时间/取消和容量/inode预算有界。归档记录的 UID/GID 不授予宿主身份，输出属主只来自可信登记策略，setuid/setgid 位清除。
- 所有数据先进入 root/0700 私有目录；源归档保留，既有目标不覆盖。全部成员字节、路径集合、空目录、模式、登记属主及纳秒 mtime 核验后，再经源/策略/父目录复核和 NO_REPLACE 发布。回执为 root/0600、单链接、有界 JSON。
- 强杀后的 Inspect/同 ID 重入仅观察，不重新解包、不把私有半成品晋升、不递归清理。输出身份和全树摘要吻合才补 Completed；已知本操作私有 inode 尚未发布则 Aborted；缺少身份或外来对象等保留 Unknown。取消不是“未产生效果”的证明；恢复观察有独立时间预算，但不被旧写取消打断。
- 本引擎不是文件系统原子快照；后续必须接入业务共享层级锁、原登录双阶段确认、当前管理权限复核、人类审计及 Unknown 管理处置。
