## 业务边界

文件浏览/inspect/下载与计划均只使用宿主登记根。上传先确认五分钟登录绑定HMAC计划，SQL原子写入永久意图、Job、Outbox和人类主体审计，返回202；二进制PUT只做宿主私有暂存/校验，不发布。独立Worker复核当前管理员、取消/期限、版本和摘要后发布，按根回执对账并保留Unknown，不自动重传。取消前置于接收时写owner绑定root tombstone，拒绝迟到上传；已完成发布不被取消撤销。文件正文、原始Cookie引用和计划token不进入SQL/Outbox/审计。

HTTP/Agent/目录/内存/并发预算保持1GiB、10分钟、32KiB块、Root四槽与64全局/4主体在途意图；同目标哈希唯一在途锁。维护入口和Gateway的较长超时/请求大小仅针对文件路由，Gateway不落盘缓冲。下载最后一块必须等待RPC完整结束、SHA与大小/版本校验及审计后才发送；下载审计Validated表示服务端流校验通过，不声称客户端已保存。普通用户和不同登录不能访问别人的上传意图；API/Worker无宿主目录或docker.sock挂载。
