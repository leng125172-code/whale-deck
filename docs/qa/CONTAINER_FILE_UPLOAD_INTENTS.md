- 浏览器等待/接收只预留同CID的路径层级并计入全局64/每主体4预算；不占全局发布权。容器准备发布时，须无宿主路径锁、无其他容器发布权，然后原子保存RootStarted和保护位。持有期间拒绝新宿主写锁及其他容器发布，以覆盖不同CID共享同一bind目录的情况。
- 过期租约不能清除发布保护。Unknown保留保护且不进入自动claim；不能把未知发布改成无锁、重发或假取消。结束前要求精确Root回执；成功要求完整大小/SHA/当前绑定，覆盖要求HDD旧版本证明。取消只接受Prevented/Discarded/PublishDiscarded，不将传输失败当成成功取消。
- 意图、Job、事件、Outbox和人类审计同一SQL事务；审计只含容器ID与路径/实例哈希，不含原路径或登录绑定。通用Worker不消费两类专属Outbox；取消路由独立，通用重试明确拒绝容器字节上传。

保护位协调Whale Deck自己的写任务，不能禁止应用进程或外部终端修改文件。实际目标版本检查、原子发布和不确定状态处理仍由已安装的受限Root引擎负责，不能据本SQL门禁宣称外部文件永不变化。
