# Worker 生成运行报告与自动退役

2026-11-09，代码 `ebd4f2fd`。P3-17 的新运行会在入队时锁定报告保留期，默认 14 天，可配置 1–365 天。Node 和 .NET 测试的启动需要 Agent 协议 1.67，已开始的运行可在仍支持运行控制和工件清单的 1.66 上观察及取消。报告 Worker 独立领取终态运行的数据库租约，使用原请求和清单读取受控工件，复核摘要并解析有界 JUnit 或 TRX。

JSON、Markdown、内容摘要、采集审计和退役状态在同一个 PostgreSQL 事务中提交。只有已入库且摘要匹配的工件进入退役队列。新 Worker 可按原请求接管并重试，原运行终态保持可查。遇到内容不匹配会保留原件，报告显示核验异常。失败、取消和结果未知都有报告状态。源码指纹当前输出未知，时间窗使用调度与结算时间。兼容旧报告的独立运行 ID 和存量运行的快照。降级会拒绝丢弃新报告工作流或已排队的报告配置。

报告附件继续走同源 BFF 路由和下载审计。具备当前开发权限且存储根获准的空间所有者可下载，既有管理员及显式组委派仍可用。
