## 9. 每个任务的完成定义

- 业务规则在 Application/Domain，Controller 只做传输，Infrastructure 只实现端口。
- Nullable、分析器、格式和架构测试通过。
- 有正常、拒绝、冲突、依赖失败、取消/回滚和权限下降测试。
- 涉及数据库时包含可回滚 EF migration 和迁移测试。
- 涉及 Agent 时包含 Unix Socket 授权、资源保护、幂等和重启恢复测试。
- 涉及前端时包含加载、空、错误、过期、无权限、暗色、响应式和减少动画状态。
- 日志为有界结构化 JSON；高频指标和成功轮询不写 Info 日志。
- 文档、API 契约、运行配置示例和安全说明同步更新。
- Secret 不进入 Git、日志、审计、截图快照或测试固定数据。
